# Docs assistant

Three-phase documentation search for LinkShift, served by **backend-tools**.

## Data sources

| Layer | Path | Role |
|-------|------|------|
| Summaries (router) | `shared/docs-summaries/` | Short summaries generated by `npm run docs:summaries` |
| Full pages (generator) | `shared/docs/pages/` | Guides, concepts, overview |
| OpenAPI by tag (generator) | `shared/docs/openapi/by-tag/*.openapi.json` | Per-tag slices from `npm run docs:openapi:split` |
| Canonical contract | `shared/docs/openapi/linkshift-api-keys.openapi.yaml` | User-facing API contract (cite this, not slice paths) |

Summaries mirror `shared/docs/` paths. OpenAPI slices are internal LLM context; the assistant must cite **OpenAPI tags** and **`METHOD /path`**, not paths like `shared/docs-summaries/openapi/by-tag/...`.

## API (backend-tools)

| Method | Path | Guards |
|--------|------|--------|
| `POST` | `/api/v1/public/docs/search` | Turnstile (`x-turnstile-token`), Throttler (5/min), Redis IP limit |
| `POST` | `/api/v1/public/docs/rate` | Throttler |

### Search body

```json
{ "question": "How do I list domain groups?" }
```

### Search response

```json
{
  "answer": "...",
  "sources": [
    "API reference: Domain Groups (/docs/reference) — LinkShift API keys OpenAPI",
    "Guide: Domains and groups (/docs/guides/domains-and-groups)"
  ],
  "logId": "uuid-or-null"
}
```

`sources` are **user-facing citations** (docs routes and API reference tags), not internal `openapi/by-tag` slice paths. Slices are LLM context only; the canonical contract is `linkshift-api-keys.openapi.yaml` at `/docs/reference`.

### Rate body

```json
{ "logId": "uuid", "rating": 1 }
```

`rating`: `1` (helpful), `-1` (not helpful), `0` (clear).

## Pipeline

1. **Router** (`DOCS_ASSISTANT_ROUTER_MODEL`, default `gpt-5.4-nano`) — intent + `catalogId` picks from summaries.
2. **Generator** (`DOCS_ASSISTANT_GENERATOR_MODEL`, default `gpt-5.4-mini`) — answer from full docs + OpenAPI outlines.
3. **Critic** (`DOCS_ASSISTANT_CRITIC_MODEL`, default `gpt-5.4-nano`) — JSON validity check.

## Configuration

See `backend-tools/.env.example`. Required for search: `OPENAI_API_KEY`. Optional: `SUPABASE_*` (logging/ratings), `CLOUDFLARE_TURNSTILE_SECRET_KEY`.

Supabase table DDL: `backend-tools/supabase/agent_search_logs.sql`.

## Frontend (not included)

Wire Cloudflare Turnstile on the docs UI, then call tools API with header `x-turnstile-token` on `POST .../docs/search`.
