Documentation assistant

The documentation assistant lets you ask questions and receive answers drawn from official documentation. You may access it wherever we make it available in the Service (such as our documentation site or signed-in areas of the app). When you submit a question, it is sent to our tools API to generate an answer. We may store the question, answer, sources cited, response time, and an optional helpful/not helpful rating in our logging database to improve quality and prevent abuse.

Recent chats can be saved in your browser’s local storage on your device so you can return to them later. You can clear that history in the assistant UI; clearing it does not delete server logs already recorded for earlier questions.

Bot protection for the documentation assistant may use Cloudflare Turnstile. Answers are generated with OpenAI using retrieved documentation context only for that request.
