Hierarchy at a glance
1. Domain group scopes your setup.
2. Domains/subdomains receive traffic.
3. Redirect rules match request paths.
4. Link maps (shortlinks) plug into a redirect rule path.
Short example
Create a rule for /go, then connect a link map. /go/docs can resolve to a dynamic destination from that map.
